1 · Install, update, shell, boot

Installer → backend-runtime/ + data/ → Tauri supervisor → port discovery → health probe → React boot → routes.

2 · One chat turn, end to end

Composer → POST /api/workbench/chat (returns sinceSeq) → background turn → provider SSE → event log → GET SSE → frame switch → turn_end + turn_outcomes. The tool surface is a session cache, keyed by its set and gates.

3 · Tool calls and the gates in front of them

exec.py:_executeTool → baseline/stale-write → PRE_TOOL_USE hooks → tool_registry.dispatch → real sandbox (hardline, backends, code_runner port), listing doors, subagent deny set, authority refusal.

4 · Memory: what the model sees, what it can write, what survives

The memory record → the turn tail (always-in profile/preference lane + the "new in memory since this chat opened" delta), with BM25 reachable only through an explicit brain_query → model CRUD via remember/list_facts/forget/brain_query → opt-in learning loop → verified backups and staged restore.

5 · Provider routing and wire formats

providers.json → per-model apiFormat override → baseUrl + leaf → body dump/strip → wireBody credential scrub → the three legs → the /v1 proxy adapters → pricing.

6 · App surfaces and navigation (the current shell)

ChatLayout + SessionListNav (New/Search/Projects/Artifacts/Customize) → routes → composer, artifacts, settings overlay and right drawer; the circuit drawer’s schematic editor owns the graph the lazy 3D stage renders.
